# 종합사회복지관 · 주간보호시설 · 일일 활동 기록 및 운영일지 시스템 (샘플)

> **실행 방식**: 기본 **샘플 체험 모드 (`mode: "sample"`)** — 별도 서버나 로그인 없이 브라우저에서 즉시 체험 가능  
> **아키텍처**: 무빌드 Vanilla HTML5 / CSS3 / JavaScript · PWA 오프라인 지원 · 선택적 Firebase Auth & Cloud Firestore 연동

종합사회복지관, 주간보호시설 등 사회복지 현장에서 사용할 수 있도록 제작된 **이용인 일일 출결 체크**, **당일 프로그램 실적 및 연간 누계 자동 합산**, **주간보호 운영일지 작성**, **공문서 1:1 A4 통합 인쇄(단독 1장 · 함께 인쇄 2장)**, **대분류 · 프로그램 · 명단 · 백업 및 계정 관리** 통합 웹 시스템 샘플입니다.

---

## 1. 샘플 체험 모드 안내

별도의 데이터베이스나 Firebase 설정 없이도 바로 화면을 띄워 시연·테스트할 수 있도록 브라우저 `localStorage` 기반의 **샘플 체험 모드**가 기본 활성화되어 있습니다.

- **초기 샘플 데이터 기본 탑재**:
  - 가상 이용인 명단(이용중 12명 · 대기 1명 · 퇴소 이력 1명, 1~16번 슬롯)
  - 최근 3일 출결(`○` 등원 · `√` 비대면 돌봄 · `X` 결석) 및 연간 누계 반영 활동 실적
  - 당일 `운영일지` 작성 예시(오전/오후 프로그램 세부내용, 담당자별 업무사항, 후원·VMS 봉사인원)
- **즉시 진입 & 권한 전환**: 접속 시 별도 로그인 장벽 없이 관리자(`김복지`) 샘플 화면으로 바로 열리며, 우측 상단 **`[권한 전환]`** 버튼으로 관리자(`김복지`) / 일반 담당자(`이돌봄`) 권한 차이를 전환해 볼 수 있습니다.
- **원클릭 샘플 초기화**: 체험 중 수정·삭제한 데이터는 브라우저에 저장되며, 상단 **`[샘플 초기화]`** 버튼으로 언제든 초기 예시 상태로 되돌릴 수 있습니다.

## 2. 기관별 맞춤 확장 포인트

- **대분류 및 프로그램 구성**: `환경 · 계정 관리` → `프로그램 · 목표치 관리` → **`[대분류 관리]`**에서 기본 1~8번 공문서 대분류 외 사용자 정의 대분류(최대 30개)와 신규 프로그램을 추가하고, 연간 목표치 및 `매일 자동등록` 루틴을 기관 특성에 맞게 조정할 수 있습니다.
- **이용인 명단 관리**: `1~16번 명단 일괄 입력`과 `이용중 · 대기 · 퇴소` 상태 관리를 통해 등록일·퇴소일 기준 과거 출결 이력을 보존합니다.
- **운영일지 담당자 설정**: `[업무사항 담당자 고정 명단 설정]`에서 실제 일지를 작성하는 사회복지사 명단과 출력 순서를 지정할 수 있습니다.

## 3. 핵심 기능 (상단 4개 탭 구성)

### 3-1. `일일 활동 기록` (`#tab1View`)
- **한국 표준시(KST) 날짜 네비게이션**: `[< 어제]` · 날짜 달력 · `[내일 >]` · `[오늘]` 및 단축키(`Alt + ← / →`), 미래 일자 배지 안내.
- **원탭 4열 세로 출결 그리드 (`1~4 / 5~8 / 9~12 / 13~16`)**:
  - 기본 전원 등원(`○`) 상태에서 결석(`X`) · 비대면 돌봄(`√`) 변동 이용인만 원탭 수정, 성함 클릭(`종일⇄`) 시 오전·오후 동시 전환(`○ → √ → X`), `[전원 등원]` 일괄 복귀 지원.
- **당일 활동 기록 & 참석인원 연동**:
  - `매일 자동등록` 루틴(`건강체크`, `건강체조`, `급식`, `간식`) 자동 생성 및 `[기본 루틴 다시 채우기]`.
  - `[+ 행 추가]` ➔ `1단계: 대분류` ➔ `2단계: 세부 프로그램` 선택, `실시횟수 (회)` · `참석인원 (명)` 입력.
  - 참석인원 **`[연동]` / `[직접]`** 모드 지원 및 행 삭제 직후 `[되돌리기]` 토스트 지원.
- **로컬 초안 버퍼링 및 안전 이탈 보호**:
  - 수정 내용은 **`[당일 기록 저장]` (`Ctrl + S`)** 클릭 시 확정 저장되며, 미저장 상태에서 이동 시 확인 모달을 표시합니다.

### 3-2. `운영일지 작성` (`#tab4View`)
- **점검 및 결석 연동**: `안전점검 완료` · `환경점검 완료` 체크박스, `[출석부 결석자 불러오기]` 및 `결석사유` 입력.
- **오전 · 오후 프로그램 및 세부내용**: `[+ 등록 프로그램 선택 추가]` 드롭다운 또는 쉼표(`,`) 직접 입력, 당일 활동 기록과 불일치 시 확인용 주황색 안내 표시.
- **담당자별 `업무사항` 및 하단 항목**: 고정 명단 또는 `[+ 당일 작성자 칸 추가]`, `후원 물품 외` · `기타 (전달사항 외)` · `주방봉사` · `VMS등록 봉사인원 (명)` 입력 후 **`[운영일지 저장]` (`Ctrl + S`)**.

### 3-3. `통합 인쇄` (`#tab2View` — 공문서 1:1 A4 출력 허브)
- **3가지 출력 서식 선택 모드 (`daily` / `journal` / `both`)**:
  - **`[일일기록지]`**: 공식 `일 일 활 동 기 록 지` A4 세로 **1장** (`기록지 날짜 표기` 체크 지원).
  - **`[운영일지]`**: 공식 `주간보호 운영일지` A4 세로 **1장** (결재란 `담당 · 선임 · 센터장` 포함).
  - **`[함께 인쇄 (2장)]`**: 당일 `일일기록지`(1쪽) + `운영일지`(2쪽)를 **A4 2페이지**로 동시 출력/PDF 저장.
- **SVG 대각선 빗금(`╱`) 및 자동 레이아웃 유지**:
  - `금일 실적(좌상단) / 연간 누계(우하단)` 자동 집계 및 2단계 압축(`.is-compact-print` / `.is-ultra-compact-print`)으로 추가 프로그램까지 A4 1장 규격 유지.
  - 운영일지 5단계(`fit-step-0`~`5`) 자동 축소 및 분량 초과 시 상단 배너 안내.

### 3-4. `환경 · 계정 관리` (`#tab3View`)
- **이용인 인적사항 관리**: 16슬롯 일괄/개별 등록 및 입·퇴소 이력 관리.
- **프로그램 · 목표치 및 `[대분류 관리]`**: 46개 기본 항목 목표치·자동등록 편집 및 신규 대분류/프로그램 CRUD.
- **데이터 백업 · 신년 초기화**: 전체 JSON 백업 다운로드(5MB 제한) · 복원 및 직전 연도 백업 자동 저장 후 신년 초기화.
- **선생님 계정 관리**: 기관 가입 코드 관리, 담당자 권한 전환, 비밀번호 변경/재설정 및 운영일지 담당자 연동.

## 5. 로컬 실행 및 실제 기관 배포

### 로컬 미리보기 (샘플 체험 모드 즉시 실행)
```powershell
cd daily-record-web
npx --yes serve . -l 5173
```
브라우저에서 `http://localhost:5173`으로 접속하면 별도 로그인 없이 바로 샘플 시스템을 체험할 수 있습니다.

### 실제 기관 클라우드 운영 전환 (선택)
1. Firebase 콘솔에서 프로젝트를 생성하고 **Authentication(이메일/비밀번호)** 과 **Cloud Firestore**를 활성화합니다.
2. `daily-record-web/firebase-config.js`에서 `mode: "sample"`을 제거하거나 `mode: "firebase"`로 변경하고, 기관 전용 `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`를 입력합니다.
3. `daily-record-web/.firebaserc`의 `"default"` 값을 해당 Firebase 프로젝트 ID로 변경한 뒤 배포합니다.
```powershell
cd daily-record-web
firebase deploy --only firestore:rules,hosting
```
